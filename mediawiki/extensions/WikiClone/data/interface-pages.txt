# simply missing.

# Footnote labels. Cite numbers a named group from these lists, and without
# them a note that should read [a] reads [lower-alpha 1] — the group's own
# name, printed because there is no label list to draw from. {{efn}} uses
# lower-alpha, so this shows up on any article with explanatory notes.
MediaWiki:Cite link label group-lower-alpha
MediaWiki:Cite link label group-upper-alpha
MediaWiki:Cite link label group-lower-roman
MediaWiki:Cite link label group-upper-roman
MediaWiki:Cite link label group-lower-greek
MediaWiki:Cite link label group-note
